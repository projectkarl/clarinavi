# ClariNavi

ClariNavi 為**唯一正式版**。前端只載入 `index.html + app.css + app.js`，沒有歷史版號 CSS / JS 疊加，也不使用 React / Vue / Chart.js 等大型前端框架。

## 這版重點


### 首頁研究工具列
- 主導覽只保留看盤高頻入口：行情、ETF、排行、自選、產業、強勢雷達。
- 投資組合、配息行事曆、股票申購、法人排行、市場警示、財經新聞、KOL、設定收進首頁單排圖示。
- 這些輔助功能不在首頁抓資料；只有點入對應頁面才啟動各自 API / 計算。
- 桌機 8 個圖示同列；手機維持單列橫向滑動，不增加首頁高度。
- 手機底部導覽改為「行情 / ETF / 排行 / 自選 / 工具」，「工具」會回首頁並定位到研究工具列。

### ETF 專區
- ETF 清單與搜尋。
- 排行：成交量、漲幅、跌幅、股價、定期定額、發行單位。
- 分類：全部、股票型、債券型、主動式、槓桿、反向、海外成分。
- 點擊 ETF 可直接進入既有個股 / ETF 研究頁。
- 首頁保留輕量「ETF 熱門」前 8 名，完整資料只在進入 ETF 專區後載入。

### 台股行情排行
- 上市＋上櫃最多前 100 名。
- 排行：股價、漲幅、跌幅、成交量、成交金額。
- 可切換：合併 / 上市 / 上櫃。
- 排行頁開啟時每 15 秒最佳努力刷新；離開頁面或瀏覽器隱藏時停止輪詢。
- 首頁只顯示前 8 名，不在首屏抓完整 100 名。

### 首頁大盤
- 加權指數與台指期維持獨立卡片。
- 加權指數在資料可得時顯示「當日價格線＋量能柱」，否則退回歷史線圖。
- 顯示成交量、成交額、成交筆數等可得市場統計。
- 點卡片可放大查看圖表與資料表。
- 首頁指數卡可自由加入 / 刪除，最多 8 張。

### 個股當日圖
- 台股分時圖：價格線＋均價線＋成交量柱。
- 5 秒快照、1 分、5 分、15 分、60 分聚合。
- 顯示今開、分時高低、均價、成交量、量比與五檔買賣力道。
- 免費公開來源無法完整回補盤中逐筆時，不製造假走勢；保持頁面開啟後逐步累積快照。
- 技術 K 線仍保留成交量、MA、布林、MACD、RSI、KD。

### 原有研究功能全部保留
- 比例式 Treemap 產業熱力圖：區塊面積＝成交金額占比，紅漲綠跌。
- 五個交易日板塊回顧：日期 BAR、Slider、播放 / 停止、前後日、逐日流動差異。
- 三大法人歷史成本：外資 / 投信 / 自營商，逐線標示實際最早與最新可得日期。
- 目標價公開樣本、本益比河流。
- 上游 / 同業 / 下游供應鏈研究。
- 自選、投資組合、投組配置圖、匿名公開 Top 10、產業、配息行事曆、雷達、KOL。
- 語音股票查詢與市場 / 個股語音說明。

## 輕量策略
1. 首頁 ETF / 行情榜只取前 8 名，且接近畫面時才載入。
2. 完整 ETF / Top 100 只在使用者進入對應頁面時請求。
3. 行情排行只在該頁可見時輪詢；ETF 專區 20 秒快取。
4. 本益比河流、供應鏈、公開投組等深度功能全部按需載入。
5. 圖表採專案內建輕量繪圖 / SVG，不新增大型第三方前端套件。
6. 投組配置圖使用 CSS `conic-gradient`。
7. Vercel API 採 route-level lazy require，只載入本次請求需要的 handler。
8. 靜態檔由 Vercel CDN 自動 gzip / Brotli 壓縮。

## 資料來源與使用界線
- 上市證券 / ETF 基本與盤後成交：TWSE OpenAPI。
- 上櫃行情 / 公司資料：TPEx OpenAPI。
- 加權指數 / 市場統計：TWSE OpenAPI；公開市況模式另以 TWSE MIS 做最佳努力盤中更新。
- 台指期：TAIFEX OpenAPI。
- 月營收 / 財報 / EPS：MOPS 公開資訊。
- 法人：TWSE / TPEx 官方公開資料。
- 集保持股結構：TDCC 官方資料。

TWSE 已授權至政府資料開放平台的資料可依其開放條款使用並應清楚註明來源；**公開轉播真正即時 / 延遲交易資訊則可能需要另行簽訂資訊使用契約**。因此介面將 MIS 資料標成「最佳努力近即時」，不宣稱為券商授權逐筆行情。若要把 ClariNavi 作為對外商業即時行情服務，部署前應另確認交易所 / 合法資訊商授權範圍。

## 美股欄位顯示原則
美股不再用「市場別」直接整批隱藏功能。前端先保留可用研究入口，實際請求資料後才依回傳內容決定是否隱藏。已確認公開/可接資料：
- Alpha Vantage：美股日線、Quote、公司 Overview/估值指標、財報、盈餘、新聞情緒、技術指標；即時/15 分延遲美股行情屬 entitlement/付費授權範圍。
- SEC data.sec.gov：Company Facts / XBRL 財務事實，免費公開，可作美股基本面備援。
- Nasdaq Data Link：有 real-time/delayed API 架構，但多數專業美股價格/基本面資料集為 premium，不假裝成免費來源。
因此只有「該功能沒有已配置來源，或來源實際回傳空值/不可用」時才隱藏，不因 US 市場身份預先刪除。
